# 속마음 조제실 · UNSAID PHARMACY

롤플레이 NPC의 무의식적 불안 분석(OOC) 결과를 붙여 넣으면, 90년대 동네 약국 컨셉으로
직접 뜯고·현상하고·찢으며 읽는 정적 사이트. 빌드 없이 HTML·CSS·ES 모듈만 쓴다.

```bash
python3 -m http.server 8000   # 로컬 확인 (ES 모듈이라 file:// 로는 안 열림)
npm test                      # 파서 테스트 (node --test, 의존성 없음)
```

`main` 에 푸시하면 `.github/workflows/pages.yml` 이 테스트 후 GitHub Pages 로 배포한다
(처음 한 번 Settings → Pages → Source 를 "GitHub Actions" 로 지정).

## 흐름

| 단계 | 은유 | 인터랙션 |
|---|---|---|
| 접수 | 처방전 | OOC 프롬프트 복사 → AI 답변 붙여넣기 → 조제하기 (예시 처방 있음) |
| STEP 1 | 블리스터 팩 12칸 (불안 지수 12종) | 칸을 누르면 낮음/중간/높음 짐작 → 은박이 찢어지며 알약 공개. 알약 색 = 구간, 크기 = 수치. 적중 표시 |
| STEP 2 | 엑스레이 필름 6장 (숨겨진 심리) | 라이트박스 스위치를 켠 뒤 필름을 1.1초 길게 눌러 현상. 애착 유형은 4분면 판독 |
| STEP 3 | 복용 주의 약봉투 (가장 깊은 불안) | 12정 + 6장을 다 봐야 봉인 해제. 절취선 손잡이를 끝까지 끌어 찢으면 편지가 타자기처럼 나옴 |
| STEP 4 | 조제 내역서 (영수증) | 전 항목 수치·평균·최고/최저·짐작 적중률과 약사 등급. PNG 저장 |

## 구조

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면 전부. 모바일 우선(3열) → 600px(4열) → 1000px(6열·필름 6장 한 줄·봉투 2단) |
| `js/items.js` | 12 + 6 항목 정의, 별칭, 구간(0–39 / 40–69 / 70–100) |
| `js/parse.js` | AI 답변 파서. 글머리·굵게·번호·콜론 변형, 앞뒤 잡담, 코드블록 허용 |
| `js/prompt.js` | 복사용 OOC 프롬프트 (원문 + 사이트가 읽기 쉬운 머리·꼬리 규칙) |
| `js/receipt.js` | 내역서 모델 → HTML / 저장용 캔버스 |
| `js/sound.js` | WebAudio 효과음(기본 끔)과 진동 |
| `js/sample.js` | 예시 처방 (가상 인물) |

## 설계 메모

- **파서**: 줄 머리에서 항목 이름(공백 무시, 가장 긴 별칭 우선)을 찾고, 그 줄의 `NN%`를 수치로 쓴다.
  이어지는 `상태값:` / `설명:` 줄을 붙이고, 접두어 없는 줄은 직전 필드에 이어 붙인다.
  `[DEEPEST ANXIETY]`·`가장 깊은 불안` 같은 **제목처럼 생긴 짧은 줄**에서만 깊은 불안 구역을 시작한다
  (설명 속 "인정하기 싫어하며…" 같은 문장에 걸리지 않게). 그 구역 첫 줄이 60자 이하면 인용문, 나머지는 해설.
- **애착 유형**: 머리 줄에 적힌 유형을 우선하고, 없으면 본문에서 가장 먼저 나온 유형 하나를 고른다.
- **최소 조건**: 전체 6개, 불안 지수 4개 이상을 읽어야 조제한다. 빠진 항목은 `기록 없음` 칸으로 두고 진행 조건에서 뺀다.
- **접근성**: 길게 누르기·끌기는 키보드(Enter)로 즉시 실행된다. `prefers-reduced-motion`이면 애니메이션·타자 효과를 끈다.
- **개인정보**: 붙여 넣은 글은 서버로 보내지 않는다. 마지막 입력만 `localStorage`에 남겨 새로고침에 대비한다(예시는 저장 안 함).
