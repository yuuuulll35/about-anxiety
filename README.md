# 마녀의 속마음 실험실 · HEARTBREW LABORATORY (`heartbrew-lab`)

롤플레이 NPC가 PC에게 느끼는 호감을 해부하는 OOC(**사랑의 묘약**) 결과를 **마녀의 솥단지**로 읽는 정적 사이트.
재료 12병은 끌리는 이유 12가지(외모·목소리·손길·향기·다정함·의외성·능력·약한 모습·대화·편안함·대하는 방식·위험한 매력),
환영 6개는 숨겨진 마음(첫 흔들림·몰래 하는 상상·사랑의 언어·질투·삼킨 고백·들키기 싫은 습관), 마지막 한 방울은 아직 하지 못한 한 마디다.
AI 분석을 보기 전에 먼저 짐작해 두고, 결과를 붙여 넣으면 재료를 솥에 부으며 짐작과 대조한다.
빌드 없이 HTML·CSS·ES 모듈만 쓴다.

```bash
python3 -m http.server 8000   # 로컬 확인 (ES 모듈이라 file:// 로는 안 열림)
npm test                      # 파서·물약 테스트 (node --test, 의존성 없음)
```

`main` 에 푸시하면 `.github/workflows/pages.yml` 이 테스트 후 GitHub Pages 로 배포한다
(처음 한 번 Settings → Pages → Source 를 "GitHub Actions" 로 지정).

## 흐름 (한 화면짜리 게임 장면)

스크롤 없이 밤의 다락방 한 칸에서 진행한다. 천장 들보에 재료 12병이 실에 매달려 흔들리고, 가운데 솥,
왼쪽 독서대의 **주문서**(책), 오른쪽 달이 보이는 창과 안내역 **검은 고양이**가 있다. 하단 HUD는
방울 12칸 · 별 6칸 · 봉랍 1칸과 "예상 물약 → 실제 물약" 작은 병으로 진행을 보여 준다.

준비 단계는 설명문 대신 **고양이 대화창 안에서 한 번에 하나씩** 묻는다(점진적 공개). 다음 입력은 앞 칸을 채워야 나타나고,
주요 버튼은 조건을 만족할 때만 켜진다. 주문서(책)는 레시피 · 메뉴(OOC 다시 복사, 예시 체험, 처음부터)만 남겼다.

| 단계 | 대화창에 나오는 것 |
|---|---|
| `intro` | 먹물의 튜토리얼 5줄. [다음 ▸]으로 한 줄씩 넘기고, 말하는 대상(병 · 주문서 · 솥)만 밝게 비춘다. 건너뛰기 가능 |
| `name` | NPC 이름 입력 하나. 비어 있으면 [다음] 꺼짐, Enter로 진행. "예시로 먼저 구경하기" |
| `pc` | PC 이름 입력 하나(선택). 비우면 버튼이 [건너뛰기] |
| `guess` | 나만의 물약 만들기. 병을 누르면 "유하의 얼굴과 모습에 자꾸 눈이 가는 마음, 서도윤은 얼마나 클까?"처럼 쉬운 말로 묻고 [옅음][보통][진함] 중 고르면 다음 병으로 넘어간다. [완성 n/12] |
| `attach` | (짐작을 마치면 "나만의 물약 완성!" 카드: 내 물약 병이 차오르고 이름 · 색을 보여 줌, 2.4초 또는 탭) 사랑의 언어 칩 5개(다정한 말·함께하는 시간·선물·챙겨 주기·스킨십) + 모르겠어 |
| `ooc` | [📋 주문 복사하기] 버튼 하나. 누르면 다음 칸이 열린다 |
| `paste` | 주문 조각 탭 ①끌림 1~6 · ②끌림 7~12 · ③숨겨진 마음. 지금 탭에는 [📋 주문 복사] 하나와 **답 붙여넣기 칸** 하나만 있다. 붙여 넣는 순간 읽어서 칸을 비우고, 받은 줄(07 08 …)을 칸 아래 표시한다. 그 조각이 다 모이면 다음 탭으로 넘어가고, 다 모이면 [솥에 불 지피기]. 클립보드 읽기 권한을 쓰지 않아 아티팩트·iframe에서도 된다. 단계 안에서는 말풍선 높이를 고정해 고양이가 움직이지 않는다 |
| `brew` → `done` | [솥에 불 지피기]를 누르면 1.6초 점화 연출(솥 테두리 불길 · 불씨 · 섬광 · "레시피 완성" 도장, transform·opacity만 사용) 뒤 병 붓기([한 번에 붓기 ▸] 자동, 또는 병을 하나씩 톡) → 젓기([한 번에 젓기 ▸]: 국자가 한 바퀴 돌 때마다 환영 하나, 끝나면 환영 6개를 한 장에 모아 보여 줌. 또는 솥을 직접 저음) → 봉랍 → 레시피 |

처음 열면 항상 빈 상태로 튜토리얼부터 시작한다. 채팅 탭에 다녀오는 중(`ooc` · `paste` 단계)만 `localStorage`로 그 자리에서 이어진다.

휴대폰 세로는 병 6×2줄 + 말풍선이 솥 위 한 줄, 가로로 넓은 화면은 병 12개 한 줄 + 말풍선이 고양이 옆.

| `js/parse.js` | AI 답변 파서. **물약 코드**(`MUL-XXXX-XXXX-XXXX-XXXX-XXXX` + `A01 상태값` 줄들 + `DEEP 속마음 \| 해설`)를 먼저 읽고, 없으면 예전 `[POTION]` 블록, 그다음 긴 형식으로 읽는다 |

| `js/brew.js` | 색 섞기(색상환 가중 평균), 색 이름, 물약 이름(과/와 조사), 달의 위상, 마녀 등급 |
| `js/cauldron.js` | 솥 SVG (불꽃·거품·김·튀는 물방울·국자) |
| `js/recipe.js` | 레시피 카드 모델 → HTML / 저장용 캔버스 |
| `js/prompt.js` | 복사용 OOC. 답변을 세 번에 나눠 받되, mind-archive처럼 **조각마다 혼자서 완결**된다(설정만 보내고 기다리게 하지 않음). 조각마다 조건·판단 원칙·그 조각의 항목 정의 6개·변환표·출력 형식을 담는다. ① 끌림 A01~A06 ② 끌림 A07~A12 ③ 숨겨진 마음 H01~H06 + DEEP(하지 못한 한 마디). 조각 766~1,045자(입력 1,500자 이하), 답 하나 600~900자. 한 줄 형식 `A01 문자 \| 상태값 \| 설명` |

## 설계 메모

- **짐작이 먼저인 이유**: 결과를 붙여 넣는 시점엔 이미 AI 답변을 읽었으므로, 짐작은 반드시 그 전에 받는다.
  붙여넣기 순간 짐작을 고정하고, 수치가 없는 항목의 짐작은 대조에서 뺀다.
- **색 섞기**: RGB 평균은 금방 진흙색이 되므로 색상환 위에서 (수치/100)² 가중 평균을 내고 채도·명도를 다시 올린다.
  짐작 솥은 옅음 20 / 보통 55 / 진함 85로 계산한다.
- **파서**: 줄 머리에서 항목 이름(공백 무시, 가장 긴 별칭 우선)을 찾고 그 줄의 `NN%`를 수치로 쓴다.
  `[UNSAID WORDS]`·`하지 못한 한 마디` 같은 **제목처럼 생긴 짧은 줄**에서만 DEEP 구역을 시작한다.
- **접근성**: 병·독서대·봉랍은 버튼, 솥은 포커스 후 Enter/Space로 한 바퀴. `prefers-reduced-motion`이면 애니메이션·타자 효과를 끈다.
- **개인정보**: 붙여 넣은 글은 서버로 보내지 않는다. 마지막 입력과 짐작만 `localStorage`에 남긴다(예시는 저장 안 함).
