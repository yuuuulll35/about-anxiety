# 마녀의 속마음 실험실 · HEARTBREW LABORATORY

롤플레이 NPC의 무의식적 불안 분석(OOC) 결과를 **마녀의 솥단지**로 읽는 정적 사이트.
AI 분석을 보기 전에 먼저 짐작해 두고, 결과를 붙여 넣으면 재료를 솥에 부으며 짐작과 대조한다.
빌드 없이 HTML·CSS·ES 모듈만 쓴다.

```bash
python3 -m http.server 8000   # 로컬 확인 (ES 모듈이라 file:// 로는 안 열림)
npm test                      # 파서·물약 테스트 (node --test, 의존성 없음)
```

`main` 에 푸시하면 `.github/workflows/pages.yml` 이 테스트 후 GitHub Pages 로 배포한다
(처음 한 번 Settings → Pages → Source 를 "GitHub Actions" 로 지정).

## 흐름 (한 화면짜리 게임 장면)

스크롤 없이 밤의 다락방 한 칸에서 진행한다. 천장 들보에 재료 12병이 실에 매달려 흔들리고, 가운데 솥,
왼쪽 독서대의 **주문서**(책), 오른쪽 달이 보이는 창과 안내역 **검은 고양이**가 있다. 하단 HUD는
방울 12칸 · 별 6칸 · 봉랍 1칸과 "예상 물약 → 실제 물약" 작은 병으로 진행을 보여 준다.

| 단계(`data-phase`) | 하는 것 |
|---|---|
| `title` | 고양이 인사 → 주문서 1장(의뢰 대상·의뢰인) |
| `guess` | AI 분석을 보기 **전에** 병을 눌러 농도 짐작(옅음 → 보통 → 진함 → 비움). 솥이 예상 색으로 섞인다. 봉인하면 고양이가 애착 유형을 묻는다 |
| `paste` | 주문서 2장에서 OOC 복사 → 3장에 AI 답변 붙여넣기 (짐작·단계는 `localStorage`에 남아 채팅 탭에 다녀와도 유지) |
| `brew` | 병을 누르면 실에서 풀려 솥으로 날아가 기울며 쏟아진다. 실제 수치로 색이 섞이고 획득 카드에 "내 짐작 → 실제" 대조 |
| `stir` | 솥 안을 원을 그리며 저으면 초록 고리가 차고, 연기 속에서 환영(숨겨진 심리)이 하나씩 떠오른다 |
| `seal` | 솥에서 봉랍 물약병이 떠오른다. 세 번 두드려 깨면 두루마리가 펼쳐지며 가장 깊은 불안이 써진다 |
| `done` | 주문서 마지막 장에 레시피 카드(예상 색 → 실제 색, 방울 수와 ✓/✕, 마녀 등급). PNG 저장 |

휴대폰 세로는 병 6×2줄 + 말풍선이 솥 위 한 줄, 가로로 넓은 화면은 병 12개 한 줄 + 말풍선이 고양이 옆.

## 설계 메모

- **짐작이 먼저인 이유**: 결과를 붙여 넣는 시점엔 이미 AI 답변을 읽었으므로, 짐작은 반드시 그 전에 받는다.
  붙여넣기 순간 짐작을 고정하고, 수치가 없는 항목의 짐작은 대조에서 뺀다.
- **색 섞기**: RGB 평균은 금방 진흙색이 되므로 색상환 위에서 (수치/100)² 가중 평균을 내고 채도·명도를 다시 올린다.
  짐작 솥은 옅음 20 / 보통 55 / 진함 85로 계산한다.
- **파서**: 줄 머리에서 항목 이름(공백 무시, 가장 긴 별칭 우선)을 찾고 그 줄의 `NN%`를 수치로 쓴다.
  `[DEEPEST ANXIETY]`·`가장 깊은 불안` 같은 **제목처럼 생긴 짧은 줄**에서만 깊은 불안 구역을 시작한다.
- **접근성**: 병·독서대·봉랍은 버튼, 솥은 포커스 후 Enter/Space로 한 바퀴. `prefers-reduced-motion`이면 애니메이션·타자 효과를 끈다.
- **개인정보**: 붙여 넣은 글은 서버로 보내지 않는다. 마지막 입력과 짐작만 `localStorage`에 남긴다(예시는 저장 안 함).
