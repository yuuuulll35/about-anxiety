# 마녀의 속마음 실험실 · HEARTBREW LABORATORY

롤플레이 NPC의 무의식적 불안 분석(OOC) 결과를 **마녀의 솥단지**로 읽는 정적 사이트.
AI 분석을 보기 전에 먼저 짐작해 두고, 결과를 붙여 넣으면 재료를 솥에 부으며 짐작과 대조한다.
빌드 없이 HTML·CSS·ES 모듈만 쓴다.

```bash
python3 -m http.server 8000   # 로컬 확인 (ES 모듈이라 file:// 로는 안 열림)
npm test                      # 파서·물약 테스트 (node --test, 의존성 없음)
```

`main` 에 푸시하면 `.github/workflows/pages.yml` 이 테스트 후 GitHub Pages 로 배포한다
(처음 한 번 Settings → Pages → Source 를 "GitHub Actions" 로 지정).

## 흐름

| 단계 | 은유 | 인터랙션 |
|---|---|---|
| 의뢰 1 | 내가 끓이는 예상 물약 | **AI 분석을 보기 전에** 재료 12병의 농도(옅음·보통·진함)와 애착 유형을 짐작. 병을 누를 때마다 단계가 바뀌고 솥 색이 섞인다. `localStorage`에 저장돼 채팅 탭에 다녀와도 남는다 |
| 의뢰 2 | 주문서 | OOC 프롬프트 복사 → 롤플 채팅에 전송 |
| 의뢰 3 | 재료 목록 | AI 답변 붙여넣기 → 솥에 불 지피기 (짐작은 이 순간 고정) |
| STEP 1 | 재료 선반 12병 (불안 지수) | 병을 누르면 코르크가 빠지고 방울이 솥으로 날아가 떨어진다. 솥 색이 실제 수치로 섞이고, "내 짐작 → 실제"를 대조 |
| STEP 2 | 솥 젓기 → 연기 속 환영 6개 (숨겨진 심리) | 솥 안을 손가락으로 원을 그리며 저으면 초록 고리가 차고, 한 바퀴 남짓마다 환영이 하나씩 떠오른다. 애착 유형은 짐작과 대조 |
| STEP 3 | 봉랍 물약병 (가장 깊은 불안) | 12병 + 6환영을 다 보면 봉랍이 물러진다. 세 번 두드려 깨면 두루마리가 펼쳐지고 타자기처럼 써진다 |
| STEP 4 | 물약 레시피 카드 | 물약 이름(가장 진한 재료 둘), 예상 물약 색 → 실제 물약 색, 재료별 방울 수와 ✓/✕, 적중률, 마녀 등급. PNG 저장 |

짐작을 건너뛰고 바로 붙여 넣어도 된다. 그때는 대조 없이 결과만 보여 준다.

## 구조

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면 전부. 모바일 우선: 선반 3열·솥 상단 고정 → 600px(4열·환영 6칸) → 1000px(솥 왼쪽 고정 + 선반 오른쪽, 봉랍 2단) |
| `js/items.js` | 12 + 6 항목 정의(재료 이름·색, 환영 이름), 별칭, 구간 |
| `js/parse.js` | AI 답변 파서. 글머리·굵게·번호·콜론 변형, 앞뒤 잡담, 코드블록 허용 |
| `js/brew.js` | 색 섞기(색상환 가중 평균), 색 이름, 물약 이름(과/와 조사), 달의 위상, 마녀 등급 |
| `js/cauldron.js` | 솥 SVG (불꽃·거품·김·튀는 물방울·국자) |
| `js/recipe.js` | 레시피 카드 모델 → HTML / 저장용 캔버스 |
| `js/prompt.js` | 복사용 OOC 프롬프트 (원문 + 사이트가 읽기 쉬운 머리·꼬리 규칙) |
| `js/sound.js` | WebAudio 효과음(기본 끔)과 진동 |
| `js/sample.js` | 예시 의뢰 (가상 인물) |

## 설계 메모

- **짐작이 먼저인 이유**: 결과를 붙여 넣는 시점엔 이미 AI 답변을 읽었으므로, 짐작은 반드시 그 전에 받는다.
  붙여넣기 순간 짐작을 고정하고, 수치가 없는 항목의 짐작은 대조에서 뺀다.
- **색 섞기**: RGB 평균은 금방 진흙색이 되므로 색상환 위에서 (수치/100)² 가중 평균을 내고 채도·명도를 다시 올린다.
  짐작 솥은 옅음 20 / 보통 55 / 진함 85로 계산한다.
- **파서**: 줄 머리에서 항목 이름(공백 무시, 가장 긴 별칭 우선)을 찾고 그 줄의 `NN%`를 수치로 쓴다.
  `[DEEPEST ANXIETY]`·`가장 깊은 불안` 같은 **제목처럼 생긴 짧은 줄**에서만 깊은 불안 구역을 시작한다.
- **접근성**: 젓기는 Enter/Space로 한 바퀴, 봉랍은 버튼 세 번. `prefers-reduced-motion`이면 애니메이션·타자 효과를 끈다.
- **개인정보**: 붙여 넣은 글은 서버로 보내지 않는다. 마지막 입력과 짐작만 `localStorage`에 남긴다(예시는 저장 안 함).
